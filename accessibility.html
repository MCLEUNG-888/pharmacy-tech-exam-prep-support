Accessibility

Help us make studying easier to use.

We aim to make Pharmacy Tech Exam Prep usable by more learners, including people who use assistive technology. Accessibility is ongoing work; we do not claim a formal compliance certification.

Using the app

The current iOS app uses Flutter interface controls with text labels and supports the device’s portrait and landscape orientations. System text scaling (Dynamic Type) and VoiceOver may help on supported screens; behavior can vary by screen and device settings. If text scaling, VoiceOver labels, contrast, or a small-screen or landscape layout makes a task difficult, please tell us.

Using this website

This site uses text links, semantic headings, a skip link, visible keyboard focus, and a responsive layout. You can navigate it with a keyboard and use browser zoom or text scaling.

Report an issue

Email MCDEVTEAM1@OUTLOOK.COM. Include your device model, iOS version, app version, the screen or step affected, your English or Spanish setting, and the assistive technology or text size you use. A screenshot can help if it does not contain private information.
