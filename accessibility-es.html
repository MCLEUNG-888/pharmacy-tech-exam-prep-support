Accesibilidad

Ayúdanos a facilitar el estudio.

Nuestro objetivo es que más estudiantes puedan usar Pharmacy Tech Exam Prep, incluidas las personas que utilizan tecnologías de asistencia. La accesibilidad requiere trabajo continuo; no afirmamos contar con una certificación formal de cumplimiento.

Uso de la app

La app actual para iOS usa controles de la interfaz de Flutter con etiquetas de texto y admite las orientaciones vertical y horizontal del dispositivo. El escalado de texto del sistema (Dynamic Type) y VoiceOver pueden ayudar en las pantallas compatibles; su comportamiento puede variar según la pantalla y la configuración del dispositivo. Si el escalado de texto, las etiquetas de VoiceOver, el contraste o el diseño en pantallas pequeñas o en horizontal dificultan una tarea, avísanos.

Uso de este sitio web

Este sitio usa enlaces de texto, títulos semánticos, un enlace para saltar al contenido, foco visible para teclado y un diseño adaptable. Puedes navegar con el teclado y usar el zoom o el escalado de texto del navegador.

Informar sobre un problema

Escribe a MCDEVTEAM1@OUTLOOK.COM. Incluye el modelo del dispositivo, la versión de iOS, la versión de la app, la pantalla o el paso afectado, la configuración de inglés o español y la tecnología de asistencia o el tamaño de texto que usas. Una captura puede ayudar si no contiene información privada.
